AI Insurance Claim Assistant
A Streamlit-based healthcare insurance assistance application.
Features
Insurance chatbot
Cashless claim guidance
Reimbursement claim guidance
Hospitalization guidance
Claim processing information
Document checklist generator
Simple interactive dashboard
Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
Deployment
This project can be deployed using Streamlit Community Cloud.
